# Security Policy

## Supported Versions

Currently, NEXUS is in active development. Only the `main` branch is supported for security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within NEXUS, please **DO NOT** open a public issue.

Instead, please send an email to the core maintainers (refer to repository contacts) or use the GitHub Security Advisory "Report a Vulnerability" feature if enabled.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.

## Security Model

NEXUS enforces strict tenant isolation and deterministic human-in-the-loop authorization. See [Security and Authorization](docs/06_SECURITY_AND_AUTHORIZATION.md) for detailed architecture assumptions.
